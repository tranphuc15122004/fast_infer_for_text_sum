# RECAP-KV V2 Lease-Headroom Implementation Plan

> Revision of the V0 plan. V0 tasks remain as completed negative-control
> infrastructure; new V2 work adds certificate math and query/K tracing.

**Goal:** Kiểm chứng Source-State Lease bằng exact query/source-K geometry trên
frozen Qwen3 target, trước khi cân nhắc physical KV tiering.

**Experiment directory:** `src/TrainingFree/`

**Hypothesis:** Query-drift certificate có thể duy trì một cold-source mass
upper bound hợp lệ trong nhiều decode token, tạo lease đủ dài và cold fraction
đủ lớn để tránh full source rescoring.

**Validation scope:** L0 pure-Python/brute-force soundness, L1 Modal smoke và
R5 pilot 20+20. Không training, không physical eviction, không quantization.

**Evaluation design:** Collector giữ future attention chỉ để đo actual cold mass
đối chiếu certificate; certificate không dùng future signal. Report ghi per
sample, per dataset, per layer/head và lease event; failure rows không được
coi là pass.

**Architecture:** Giữ V0 modules làm negative controls. Thêm `lease.py` cho
log-domain bound và simulator; `lease_collector.py` làm Qwen3 hook/cache
boundary; integration runner thêm lease mode; Modal runner giữ image, venv,
checkpoint và Volume hiện có.

**Spec:** `src/TrainingFree/plans/2026-09-18-recap-kv-v0-design.md` (phần V2 ở đầu file)

block index/hidden vectors, segment vectors và source attention.

**Implementation details:**

- Reuse `render_document_prompt` and `_chunked_prefill` conventions.
- Force eager attention for incremental `output_attentions=True`.
- Keep only averaged last-query source attention and pooled vectors; never
  serialize full attention matrices.
- Segment boundary ưu tiên `. ! ?`, fallback fixed `segment_tokens`.
- Record checkpoint path/id, dtype, device, source span, config, seed and
  per-sample error.

Collector unit tests chỉ test pooling, segmentation, finite serialization
trên tensors nhỏ; no model load.

## Subtask 6: Query-drift certificate math (NEW V2)

**Role:** Cung cấp pure-Python, log-domain certificate không phụ thuộc Torch,
HF hoặc Modal.

**Files:**

- Create: `src/TrainingFree/lease.py`
- Test: `src/TrainingFree/tests/test_lease.py`

**Interfaces:**

- `select_hot_cold(anchor_mass, delta_anchor) -> tuple[list[int], list[int]]`
- `certificate_from_anchor(log_z0, kappa, hot, cold, live_log_z, drift) -> float`
- `actual_mass(logits, indices) -> float`
- `evaluate_certificate(anchor, current) -> dict[str, float | bool]`
- `LeaseState.step(current_query, current_live_log_z, actual_cold_mass) -> dict`

**Required tests:**

1. A brute-force random fixture verifies `actual_cold_mass <= bound + 1e-5`
   for bounded query displacement.
2. `select_hot_cold` keeps anchor mass at least `1 - delta_anchor` and has
   deterministic tie-breaking.
3. Log-domain math remains finite for logits with magnitude 1000.
4. Zero cold mass and empty live set do not produce NaN.
5. Lease expires exactly at the first step whose certificate exceeds
   `delta_cert` and refreshes the anchor.

**Verification:** write tests first and confirm RED; implement minimal math;
run `python3 -m pytest -q src/TrainingFree/tests/test_lease.py` and confirm
GREEN before integration.

## Subtask 7: Qwen3 query/source-K lease collector (NEW V2)

**Role:** Capture exact rotated Q, source K geometry and actual attention mass
at the model boundary without modifying the model cache.

**Files:**

- Create: `src/TrainingFree/lease_collector.py`
- Modify: `src/TrainingFree/schema.py`
- Test: `src/TrainingFree/tests/test_lease_collector.py`

**Implementation:**

- Register temporary pre-forward hooks on Qwen3 self-attention modules to
  capture the final query head vectors after Q projection and RoPE.
- Read source K from `DynamicCache.layers[layer].keys`; support tuple cache as a
  compatibility path.
- Expand/group GQA query heads to the corresponding KV heads.
- At each anchor compute block `log_z0`, `kappa`, hot/cold sets and exact live
  contribution in log space.
- Between anchors compute `D_t`, certificate bound, actual cold mass, lease
  validity and refresh events. Keep generated/live KV resident; do not evict.
- Serialize only block summaries and per-step lease metrics, not full source K.

**Tests:** fake Qwen3 attention/cache fixtures cover hook capture, GQA mapping,
block boundaries, finite serialization and schema round-trip without loading a
model.

**Outputs:** `lease_metrics.json`, `lease_metrics.jsonl`,

- certificate validity;
- headroom/lease statistics;
- exploratory actual-vs-bound observations;
- physical-tiering decision (`GO` or `STOP`).

**Gate:** `GO_PHYSICAL_FOLLOWUP` only when violation rate `<=1e-3`, certified
cold fraction `>=0.20`, median lease `>=4`, and refresh saving is positive;
otherwise `STOP_BEFORE_PHYSICAL`.

**Verification:** run package tests, compileall, Modal smoke, then the 40-sample
pilot with a unique run ID. Download only small metrics/manifest/report files
for review; leave trace artifact in Volume.
