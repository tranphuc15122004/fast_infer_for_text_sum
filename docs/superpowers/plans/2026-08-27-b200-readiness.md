# B200 GPU Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cung cấp đường chạy production bằng `python3` trên B200 và đường mô phỏng local bằng `.venv/bin/python`, kèm preflight và one-sample smoke report cho toàn bộ baseline.

**Architecture:** Giữ các launcher baseline làm boundary, bổ sung shared interpreter resolver có thể nhận command name hoặc absolute path, một GPU preflight có text/JSON output, và một runner điều phối không dừng khi một baseline bị block. Không thay đổi thuật toán vendored hoặc biến CPU path thành GPU pass.

**Tech Stack:** Bash, Python 3.12, PyTorch/CUDA, JSONL, pytest, các launcher hiện có trong `scripts/`.

**Spec:** `docs/superpowers/specs/2026-08-27-b200-readiness-design.md`

## Global Constraints

- B200 production dùng `python3` từ PATH, không yêu cầu activate virtualenv.
- Local simulation dùng `.venv/bin/python` qua `FAST_INFER_PYTHON`.
- Không cài package/model qua internet và không tự sửa baseline vendored.
- GPU-only baseline phải fail/block rõ ràng nếu CUDA hoặc compiled extension thiếu.
- Smoke report chỉ ghi `PASS` sau khi output/schema và runtime checks thực sự pass.
- Mọi thay đổi phải giữ regression tests hiện có và output schema hiện tại.
