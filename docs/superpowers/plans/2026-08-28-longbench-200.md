# LongBench 200 Canonical Dataset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and validate a reproducible offline LongBench test set of five datasets with 200 records each, a shared JSONL schema, stable IDs, official task prompts, and task-aware evaluation metadata.

**Architecture:** `scripts/common/benchmark_data.py` owns schema normalization, official prompt rendering, stable IDs, token-length statistics, stratified selection, and output validation. `scripts/build_longbench_200.py` reads mirrored LongBench JSONL files, calls those pure helpers, and writes a new output directory plus manifest. Existing `representative_100` remains untouched until the small-scale result is approved; the later integration updates runner/collector defaults and documentation.

**Tech Stack:** Python 3.12, standard-library JSON/JSONL, `transformers` tokenizer loaded offline, `pytest`, SHA-256, deterministic `random.Random`, JSON configuration.

**Spec:** `docs/superpowers/specs/2026-08-28-longbench-200-design.md`

## Global Constraints

- Source access is offline-only; the builder must never call a remote dataset API.
- The canonical tasks are `gov_report`, `qmsum`, `multi_news`, `lcc`, and `repobench-p`.
- Full scale is exactly 200 selected records per task; LCC and RepoBench-P use five length bins with 40 records per bin.
- `input_tokens` is measured on the official task prompt with the configured tokenizer, not by word count.
- Canonical records keep `context`, `input`, `answers`, and `reference_output`; prompts are rendered outside raw JSONL.
- Generated output goes to a new directory and refuses overwrite unless `--force` is passed.
- Full-scale processing is forbidden until small-scale tests and analysis pass and the user explicitly approves scaling.
- User-facing documentation is Vietnamese and benchmark outputs do not enter `outputs/`.

def fake_tokenizer(text, add_special_tokens=False):

def test_canonicalize_record_has_shared_schema_and_stable_id():
    source = {"context": "class A:\n    pass", "input": "", "answers": ["\n"]}
    first = canonicalize_record("lcc", 7, source, fake_tokenizer)
    second = canonicalize_record("lcc", 7, source, fake_tokenizer)

    assert first == second
    assert first["task_type"] == "code_completion"
    assert first["reference_output"] == "\n"
    assert first["input_tokens"] == len(render_prompt(first).split())


def test_stratified_sample_is_reproducible_and_balances_five_bins():
    rows = [{"id": str(i), "input_tokens": i, "source_index": i}
            for i in range(500)]
    selected = stratified_sample(rows, n=200, n_bins=5, seed=42)

    assert [row["length_bin"] for row in selected].count(0) == 40
    assert [row["length_bin"] for row in selected].count(4) == 40
    assert [row["id"] for row in selected] == [
        row["id"] for row in stratified_sample(rows, n=200, n_bins=5, seed=42)
    ]


def test_validate_output_dir_rejects_duplicate_ids(tmp_path):

- [ ] **Step 2: Implement schema normalization and prompt rendering**

`canonicalize_record` must:

```python
task_type = "code_completion" if dataset in {"lcc", "repobench-p"} else "summarization"
context = "" if source.get("context") is None else str(source["context"])
query = "" if source.get("input") is None else str(source["input"])
answers = source.get("answers") or []
if not isinstance(answers, list) or not answers or any(not isinstance(x, str) for x in answers):
    raise ValueError(f"{dataset}[{source_index}]: answers must be a non-empty list of strings")
record = {
    "id": stable_id(dataset, source_index, context, query),
    "dataset": dataset,
    "source_split": "test",
    "source_index": source_index,
    "task_type": task_type,
    "context": context,
    "input": query,
    "answers": answers,
    "reference_output": answers[0],
    "input_tokens": len(tokenizer(render_prompt({"dataset": dataset, "context": context, "input": query}), add_special_tokens=False)["input_ids"]),
    "length_bin": None,
}
```

`stable_id` uses the first 16 hexadecimal SHA-1 characters of the UTF-8 bytes
`dataset + "\0" + source_index + "\0" + context + "\0" + input`, prefixed by
the dataset name. `render_prompt` loads the versioned config and formats only
`context` and `input`.

- [ ] **Step 3: Implement deterministic five-bin selection**

Sort rows by `(input_tokens, source_index)`, split the sorted list into balanced
contiguous bins, use `random.Random(f"{seed}:{dataset}")`, select the requested
number from each bin, set `length_bin` to `0..n_bins-1`, and return selected rows
sorted by `source_index`. Raise `ValueError` when the source has fewer than `n`
rows or `n` is not divisible by `n_bins`.

- [ ] **Step 4: Implement strict record/output validation**

`validate_record` checks required keys, task type, non-empty context, non-empty
answers, `reference_output == answers[0]`, non-negative integer `input_tokens`,
and `length_bin` equal to `None` or an integer in `0..4`. `validate_output_dir`
checks the five expected JSONL files, valid JSON objects, unique IDs, matching
dataset names, exact count, manifest presence, and manifest selected counts.
